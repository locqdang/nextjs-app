# Data Model: New Menus and HARO Navigation

## Global Navbar Group

Represents one of the two top-level groups in the main navbar.

**Variants**

- public navigation group
- service and account group

## Account Menu State

Represents the actions shown based on authentication state.

**Variants**

- logged-out state
- logged-in state

## HARO Desktop Navigation Context

Represents the desktop route context that swaps the left-side navbar items to HARO-specific links.

## HARO Mobile Section Switcher

Represents the compact local dropdown used to move between HARO sections on mobile.
